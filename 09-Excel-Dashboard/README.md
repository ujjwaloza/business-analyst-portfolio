# Excel Sales Dashboard

## Project Overview

This project is an interactive Sales Dashboard developed using Microsoft Excel to analyze sales performance and support business decision-making.

## Features

- KPI Cards
- Pivot Tables
- Pivot Charts
- Slicers
- Monthly Sales Analysis
- Region-wise Sales Analysis
- Product-wise Sales Analysis
- Interactive Dashboard

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

## Business Insights

The dashboard helps business users analyze:

- Overall Sales Performance
- Regional Performance
- Top Selling Products
- Monthly Sales Trends
- Sales Distribution

## Skills Demonstrated

- Data Cleaning
- Data Analysis
- Dashboard Design
- Business Analytics
- Reporting
